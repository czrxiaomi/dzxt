# 花地湾打字练习系统 · 使用说明书

**广东实验中学荔湾学校花地湾校区（初中部）学生打字练习系统**

- 网站地址：https://czrxiaomi.github.io/dzxt/
- 建议浏览器：Safari / Chrome / Edge（最新版）
- 数据保存在云端，换电脑、换浏览器登录同一账号，成绩都在

---

## 一、学生怎么用

### 1. 注册（第一次使用）
1. 打开网站，点「注册」
2. 身份选 **学生**
3. 填写：学号、班级、密码（至少 6 位）、确认密码（学生**不用填姓名和邮箱**）
4. 点「学生注册」

> 注册成功会**直接进入学生主页**，不用去邮箱点验证链接。
> 学号不能和别人重复，重复会提示「该学号已注册」。
> 学生账号在系统内部用「学号 + 固定后缀」作为账号标识，仅用于区分身份，**不会向任何人发送邮件**。

### 2. 登录
- 打开网站 → 在「学号 / 邮箱」输入框填**学号** + 密码 → 登录 → 自动进入学生主页
- 登录过一次后，短时间内再打开网站会自动保持登录

### 3. 打字练习
1. 学生主页点「开始练习」
2. 选一篇文章（中文/英文都有），或点随机
3. 开始输入：
   - **打对的字变绿**，**打错的字变红**
   - 右上角实时显示：正确率、速度（字/分钟）、用时
4. 打完自动出成绩，并**自动保存到云端**
5. 中途想退出会提示确认，防止误触丢成绩

### 4. 看历史成绩
- 学生主页 →「历史成绩」区域，能看到每次练习的时间、文章、正确率、速度
- 如果当时断网没存上，页面会提示，点一下就能补传

### 5. 注意事项
- 练习文章和成绩区域的文字**不能复制**（防作弊），这是正常的
- 输中文需要切换到拼音输入法，打完拼音按空格/数字选字上屏

## 二、老师怎么用

### 1. 注册（老师账号）
1. 打开网站，点「注册」
2. 身份选 **教师**
3. 填写：姓名、邮箱、密码（老师不需要填学号和班级，仍用邮箱注册与登录）
4. 点「教师注册」→ 直接进入**教师端（管理端）**

> 老师账号是自己在网站上注册的，不用找管理员开。

### 2. 教师端三个功能

| 功能 | 能做什么 |
|---|---|
| **学生管理** | 查看全部学生列表、搜索；对学生账号「停用 / 启用」（停用后该学生无法登录） |
| **文章库管理** | 新增、编辑、删除练习文章；设置分类（中文/英文）、难度、是否上架 |
| **成绩统计** | 按文章、按班级、按学生三种口径查看正确率与速度汇总 |

### 3. 常用操作
- 想让某篇文章暂时不让学生看到：在文章管理里把它**下架**（不是删除）
- 学生转班/换人：管理员可在云端后台改资料；日常老师可只管启用状态

## 三、常见问题

| 问题 | 说明 |
|---|---|
| 注册后没反应 / 进不去 | 检查必填项是否漏填、密码是否满 6 位、学号是否已被占用（教师需检查邮箱格式） |
| 学生登录时填什么 | 填**学号**（不是邮箱）；教师才用邮箱登录 |
| 忘记密码 | 目前需管理员在云端后台（Supabase）帮你重置 |
| 换了电脑成绩还在吗 | 在，数据存在云端，登录同一账号就能看到 |
| 为什么文章不能复制 | 系统防作弊设计，学生端禁止复制练习内容 |
| 网页上那行淡淡的水印是什么 | 「大家好我是小咪--@bilibili制作」，制作者署名 |
| 打开很慢 / 白屏 | 检查网络；页面加载失败会有文字提示，不会一直白屏 |
